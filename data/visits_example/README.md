# Visits edge-case example

A small example for maximal visits, shifts and waiting times (`docs/resources/visits.md`), made to cover their edge cases; used by `notebooks/visits.ipynb` (section 6) and `backend-modules/location-ocpm/tests/test_visits.py`.
Generated by `make_visits_example.py` (the single source; never edit the outputs by hand): `uv run python data/visits_example/make_visits_example.py`.

- `relations.csv`: 41 relations of five handling units h1 to h5 (one event each), in the format of a saved level mapping (`derivation/level_files.py`); `loc` is given directly, ⊥ is an empty cell.
- `locations.csv`: A1, A2 and the crane C1 map to A, B1 to B; the truck T is not mapped; C1 and T are vehicles.
- `processing_events.csv`: the processing operations P (e1, e10, e35, e36, e37, e40; e37 and e40 are movements).
- Meant for κ = 1. Time t is 2026-01-01 00:00 plus t hours.

| handling unit | edge cases |
|---|---|
| h1 | all four transfer categories in one visit; vehicle shift via a vehicle inside (C1) and outside (T) of the high-level location; T visited twice (cut by κ); entry by processing |
| h2 | vehicle relations at the start and end of a visit (not shifts); vehicle visits; visit without processing |
| h3 | ⊥ relations: two ⊥ visits (κ(⊥) = 0); ⊥ inside a transfer (external shift) |
| h4 | transferring visit; A visited twice (cut by κ) |
| h5 | waiting times: entry without processing, processing on a vehicle in A, processing during an excursion, processing movements as exit and entry, trace end |
