# Visit-mapping example

The running example extended by sheets (Level 3) and the extra traces of the working note `claude_notes/visit-mapping-sets.md` (sections 6.5 and 6.7), for mapping sets derived from maximal visits (`docs/resources/visit-mapping.md`); used by `notebooks/visit_mapping.ipynb` and `backend-modules/location-ocpm/tests/test_visit_mapping.py`.
Generated by `make_mapping_example.py` (the single source; never edit the outputs by hand): `uv run python data/mapping_example/make_mapping_example.py`.

- `relations.csv`: 54 relations of ten handling units (sheets b1 to b8, slabs s1, s2; events e1 to e41), in the format of a saved level mapping (`derivation/level_files.py`); `loc` is given directly, ⊥ is an empty cell.
- `extra_relations.csv`: the extra traces x1 to x5 (events f1 to f28) and y1 to y5 (events g1 to g28), same format.
- `locations.csv`: A1, A2 map to A, the storage unit B1 to B; the truck T is not mapped and a vehicle.
- `processing_events.csv`: the processing operations P of both files.
- `derived/`: the S6 mapping set of `relations.csv`, written by the notebook (`save_mapping`).
- Meant for κ = 3. Event eK, fK, gK happens at 2026-01-01 00:00 plus K hours.

| handling units | what they show |
|---|---|
| s1, b3, b5 | maximal visits that are already disjoint (b5: a ⊥ visit) |
| b1, b2, b4, s2, b6, b7, b8 | overlapping or contained maximal visits; Nina's target resolutions in the working note, 4.1 |
| x1 to x5, y1 to y5 | further cases for the strategies (round trips, alternating locations, ⊥ inside a stay, vehicle detours); Nina's resolutions in the working note, 6.6 and 6.8 |
