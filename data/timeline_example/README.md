# Object timeline edge cases

A small example for the object timeline (`docs/resources/object-timeline.md`), covering what the running example does not have.
Generated by `make_timeline_example.py` (never edit the outputs by hand).
It is given directly as a location mapping (`relations.csv`, same columns as `data/running_example/derived/locations_level_{k}.csv`), so `loc` and `ploc` are written by hand and not derived from a log.

Locations: X1 → X; Y1, Y2, Y3 and the crane C → Y ($V$ = {C}); the furnace F is unmapped (its own high-level location).
Processing operations $P$ = {x5, x6}; transformation events $T$ = {x3, x4, x5}.
